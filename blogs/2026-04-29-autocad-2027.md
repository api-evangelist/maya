<p class="wp-block-paragraph">前バージョンから AutoCAD 2027（Windows 版）への互換性をまとめてご案内したいと思います。</p>



<p class="wp-block-paragraph"><strong>図面ファイル形式</strong></p>



<p class="wp-block-paragraph"><a href="https://adndevblog.typepad.com/technology_perspective/2018/03/new-features-on-autocad-2019-part1.html" rel="noopener noreferrer" target="_blank"></a>AutoCAD 2027、AutoCAD LT 2027 では、引き続き、<strong>2018 図面ファイル形式</strong>&nbsp;を採用しています。新規図面を作成して保存する際には、この 2018 図面ファイル形式が既定値となります。</p>



<p class="wp-block-paragraph">もちろん、旧バージョンの図面ファイル形式を開いたり、保存したりする機能も従来通りです。</p>



<p class="wp-block-paragraph"><strong>図面読み込み：</strong></p>



<ul class="wp-block-list">
<li>すべての AutoCAD バージョンで作成した DWG ファイル （<a href="https://blog.autodesk.io/whta-is-trusteddwg/" rel="noreferrer noopener" target="_blank">非TrustedDWG</a>&nbsp;を除く）</li>



<li>すべての AutoCAD バージョンで作成した DXF ファイル</li>
</ul>



<p class="wp-block-paragraph"><strong>図面の保存：</strong></p>



<ul class="wp-block-list">
<li>R14, 2000, 2004, 2007, 2010, 2013, 2018 形式の DWG ファイル</li>



<li>R12, 2000, 2004, 2007, 2010, 2013, 2018&nbsp; 形式の DXF ファイル</li>
</ul>



<p class="wp-block-paragraph"><strong>アドイン アプリケーションの互換性</strong></p>



<p class="wp-block-paragraph">AutoCAD 2027 は、AutoLISP/Visual LISP、ActiveX オートメーション（COM）、ObjectARX、.NET API、JavaScript API の 5 &nbsp;つの AutoCAD API をサポートします。前バージョンの AutoCAD 2026 からは <strong>バイナリ非互換リリース </strong>となるため、前バージョン用に作成されたアドイン アプリケーションは、移植作業が必要になります。</p>



<figure class="wp-block-image size-large"><img alt="A timeline displaying the evolution of AutoCAD versions from 2013 to 2027, highlighting milestones in interface and API customization." class="wp-image-50805" height="576" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/03/compatibility-1.jpg?resize=1024%2C576&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph">過去バージョンと、その前バージョンからの互換状況、また、移植に必要となる基本情報は次のとおりです。</p>



<figure class="wp-block-image size-large"><img alt="Table displaying compatibility information for ACAD versions, including API support, DWG file versions, Visual Studio compatibility, and .NET versions." class="wp-image-51045" height="250" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/migration_info-1.png?resize=1024%2C250&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph"><strong>自動ローダー</strong></p>



<p class="wp-block-paragraph">アドイン アプリ運用時のセキュリティを向上させる目的で、前バージョンの AutoCAD 2026 でパッケージ バンドルを使用する自動ローダーの検出に一部変更が加えられています。もし、AutoCAD 2025 以前のバージョンから AutoCAD 2027 へ移行する場合には、次の記事をご確認ください。</p>



<ul class="wp-block-list">
<li><a href="https://forums.autodesk.com/t5/autodesk-community-tips-adnopun/autocad-2026-deno-zi-dongrodano-bian-geng/ta-p/13388883" rel="noopener" target="_blank">AutoCAD 2026 での自動ローダーの変更</a></li>
</ul>



<p class="wp-block-paragraph"><strong>サポート コンパイラ</strong></p>



<p class="wp-block-paragraph">ObjectARX と .NET API でサポートされるコンパイラは、次の Visual Studio バージョンとなります。</p>



<p class="wp-block-paragraph"><strong>ObjectARX</strong></p>



<ul class="wp-block-list" id="GUID-2A0C6C5A-9C98-465F-BFB6-012A4899F53A__UL_F796DAC059C44F64B5C4118D5FCA4A82">
<li>Microsoft® Visual Studio® 2026 version 18.0 with VC tools version 14.44.35207（推奨）</li>



<li>Microsoft Visual Studio 2022 version 17.14.9</li>
</ul>



<p class="wp-block-paragraph"><strong>AutoCAD .NET API</strong></p>



<ul class="wp-block-list" id="GUID-2A0C6C5A-9C98-465F-BFB6-012A4899F53A__UL_6535A4E1FF8448ADBE64E64247401EE1">
<li>Microsoft Visual Studio 2026 version 18.0</li>
</ul>



<p class="wp-block-paragraph">ObjectARX を使った開発をする場合には「<strong>C++ によるデスクトップ開発</strong>」を、.NET API を使った開発をする場合には「<strong>.NET デスクトップ開発</strong>」をそれぞれ選択してください。</p>



<figure class="wp-block-image size-large"><img alt="Screenshot of the Visual Studio Professional 2026 installation interface, displaying options for .NET and C++ desktop development with various programming tools and frameworks." class="wp-image-50815" height="518" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/vs_installer-1.jpg?resize=1024%2C518&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph"><strong>ObjectARX</strong></p>



<p class="wp-block-paragraph">前バージョンの AutoCAD 2026 用に作成したアドイン アプリケーションをお持ちの場合には、<strong><a href="https://www.autodesk.com/developer-network/platform-technologies/autocad/objectarx" rel="noopener noreferrer" target="_blank">https://www.autodesk.com/developer-network/platform-technologies/autocad/objectarx&nbsp;</a></strong>から ObjectARX SDK for AutoCAD 2027 をダウンロード、参照して新しい開発環境となる&nbsp;<strong>Visual Studio 2026&nbsp;</strong>で再ビルドする必要があります。それ以前の既存プロジェクトの移植では、この作業が必須となります。プロジェクトに設定する「プラットフォーム ツールセット」は <strong>v145 for Microsoft C++ Build Tools</strong>（推奨：Visual Studio 2026）、または &nbsp;<strong>Visual Studio 2022(v143)&nbsp;</strong>（Visual Studio 2022）になります。</p>



<figure class="wp-block-image size-full"><img alt="Screenshot of configuration settings in a software development environment, showing platform toolset options including 'v145 for Microsoft C++ Build Tools' and related settings." class="wp-image-50896" height="470" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/platform_toolset.png?resize=1252%2C470&#038;ssl=1" width="1252" /></figure>



<ul class="wp-block-list is-style-checkmark-list">
<li>ObjectARX SDK for AutoCAD に含まれるサンプル（samples フォルダの Unmanaged C++ プロジェクト）は、Visual Studio 2022 の利用を考慮して、プラットフォーム ツールセットの値が &nbsp;<strong>Visual Studio 2022(v143) </strong>に設定されています。</li>
</ul>



<p class="wp-block-paragraph">リンクするスタティック リンク ライブラリは、ObjectARX SDK for AutoCAD 2027 の <strong>*26.lib</strong>&nbsp;に変更してください。</p>



<p class="wp-block-paragraph">ObjectARX でカスタム オブジェクトを定義していて、COM サーバーとしてオブジェクト、メソッド、プロパティを COM で公開している場合には、.idl ファイルでインポートしているタイプライブラリも&nbsp;<strong>acax26enu.tlb</strong>&nbsp;ないし、<strong>acax26jpn.tlb</strong>&nbsp;に置き換える必要があります。</p>



<p class="wp-block-paragraph">廃止、変更されたクラスや関数については、ObjectARX SDK for AutoCAD 2027 の docs フォルダの <strong>Reference Guide（arxref.chm）</strong>から<strong>&nbsp;ObjectARX Migration Guide</strong>&nbsp;セクション、または、<strong><a href="https://help.autodesk.com/view/OARX/2027/JPN/?guid=OARX-RefGuide-ObjectARX_Migration_Guide" rel="noreferrer noopener" target="_blank">オンラインヘルプ</a></strong>&nbsp;をご確認ください。&nbsp;</p>



<figure class="wp-block-image size-large"><img alt="Screenshot of Autodesk ObjectARX for AutoCAD 2027 Reference Guide, featuring the ObjectARX Migration Guide section with a list of moved classes and their descriptions." class="wp-image-50840" height="393" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/oarx_migration_guide.png?resize=1024%2C393&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph">以前の AutoCAD からの互換情報については、AutoCAD 2027 のオンライン ヘルプ、<strong><a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-C21B8F00-C7DE-4E44-8006-D5DC99199F31" rel="noreferrer noopener" target="_blank">ObjectARX の互換性</a></strong>&nbsp;もご確認ください。</p>



<p class="wp-block-paragraph">AutoCAD 2027 の ObjectARX Wizard は、<strong><a href="https://www.autodesk.com/developer-network/platform-technologies/autocad" rel="noopener noreferrer" target="_blank">https://www.autodesk.com/developer-network/platform-technologies/autocad</a></strong> で Visual Studio 2026 用に今後公開する予定です。（Visual Studio 2026 側の Wizard <a href="https://developercommunity.visualstudio.com/t/VsWizardVsWizardEngine-vsz-based-projec/11071541" rel="noreferrer noopener" target="_blank">問題</a>の修正待ち）</p>



<p class="wp-block-paragraph">インストール時には、<strong><a href="https://forums.autodesk.com/t5/autodesk-community-tips-adnopun/objectarx-objectarx-wizard-noinsutoru/ta-p/12921563" rel="noopener" target="_blank">ObjectARX：ObjectARX Wizard のインストール</a>&nbsp;</strong> もご確認ください。インストール後に Visual Studio に ObjectARX Wizard が表示されない場合には、<a href="https://forums.autodesk.com/t5/autodesk-community-tips-adnopun/objectarx-objectarx-wizard-ga-visual-studio-xin-guipurojekutoni-biao-shisarenai/ta-p/11995266" rel="noopener" target="_blank"><strong>ObjectARX：ObjectARX Wizard が Visual Studio 新規プロジェクトに表示されない</strong></a>&nbsp;の記事をご確認ください。</p>



<p class="wp-block-paragraph">また、正しくインストールされた&nbsp; ObjectARX Wizard を使用した場合でも、Wizardの [MFC Support] 画面で&nbsp;<strong>Extension DLL using MFC shared DLL(recommended for MFC support)</strong>&nbsp;オプションにチェックしてプロジェクトを作成した場合、プロジェクト作成直後に作成されたプロジェクトがロードされず、[新しいプロジェクト] ダイアログが再度表示されてしまう場合には、お使いの Visual Studio 2026 に MFC コンポーネントがインストールされていない可能性があります。MFC コンポーネントは､コントロール パネル &gt;&gt; プログラムのアンインストール から、<strong>Microsoft Visual Studio Installer</strong>、または、<strong>Visual Studio 2026</strong>&nbsp;を選択後、「<strong>変更</strong>」をクリックすると、Visual Studio 2026 のインストール後でも確認やインストール指示が可能です。</p>



<figure class="wp-block-image size-large"><img alt="Visual Studio Professional 2026 interface showing installation options and components for .NET and C++ development, including selections for various frameworks and tools." class="wp-image-50891" height="517" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/C_mfc_install.jpg?resize=1024%2C517&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph"><strong>.NET API</strong></p>



<p class="wp-block-paragraph">サポートされる .NET バージョンは .<strong>NET&nbsp; 10.0</strong> です。.NET Framework ベースの AutoCAD 2024 以前に作成したアドイン アプリケーションをお持ちの場合には、Visual Studio プロジェクトをアップグレード後、AutoCAD 2027 のアセンブリ ファイルを参照して再ビルドする必要があります。 </p>



<figure class="wp-block-image size-large"><img alt="Diagram showing the evolution of AutoCAD versions and .NET frameworks from AutoCAD 2024, linked to .NET Framework 4.8, transitioning to AutoCAD 2025/2026 with .NET 8, and progressing to AutoCAD 2027 with .NET 10." class="wp-image-51435" height="491" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/dotnet_migration.png?resize=1024%2C491&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph">なお、現在、Microsoft はプロジェクトのアップグレードに、従来の &nbsp;<strong><a href="https://blog.autodesk.io/autocad-2025-dotnet8-migration/" rel="noreferrer noopener" target="_blank">.NET Upgrade Assistant</a></strong>（.NET アップグレード アシスタント）に替わって、<strong><a href="https://learn.microsoft.com/ja-jp/dotnet/core/porting/github-copilot-app-modernization/overview" rel="noreferrer noopener" target="_blank">GitHub Copilot モダン化</a></strong> を利用した方法を推奨しています。具体的な内容は、<strong><a href="https://learn.microsoft.com/ja-jp/dotnet/core/porting/github-copilot-app-modernization/how-to-upgrade-with-github-copilot" rel="noreferrer noopener" target="_blank">GitHub Copilot モダン化を使用して .NET アプリをアップグレードする方法</a></strong>をご確認ください。</p>



<figure class="wp-block-image size-full"><img alt="Screenshot of GitHub Copilot Chat interface showing the welcome message for upgrading from .NET Framework to .NET 10, including instructions and assessment status." class="wp-image-51317" height="591" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/github_copilot-1.jpg?resize=732%2C591&#038;ssl=1" width="732" /></figure>



<p class="wp-block-paragraph">&nbsp;.NET 10.0 への移行に際しては、Visual Studio Installer から、Visual Studio 2022 の [個別のコンポーネント] で「.NET 10.0 Runtime」または「.NET 10.0 ランタイム 」を先にインストールしておく必要があります。</p>



<figure class="wp-block-image size-large"><img alt=".NET version selection menu in Visual Studio Professional 2026, highlighting .NET 10.0 WebAssembly Build Tools with checkboxes for various components." class="wp-image-50838" height="518" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/Net10_runtime_install.jpg?resize=1024%2C518&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph">一部のクラスやメソッド、プロパティが変更されている場合がありますので、ソースコードに適切な変更を加える必要があります。</p>



<p class="wp-block-paragraph">廃止、変更されたクラスやメソッド、プロパティについては、ObjectARX SDK for AutoCAD 2027 の docs フォルダの <strong>Managed Class Reference Guide（arxmgd.chm）</strong>から&nbsp;<strong>.NET Migration Guide</strong>&nbsp;セクションセクション、または、<strong><a href="https://help.autodesk.com/view/OARX/2027/JPN/?guid=OARX-ManagedRefGuide-_NET_Migration_Guide" rel="noreferrer noopener" target="_blank">オンラインヘルプ&nbsp;</a></strong>をご確認ください。&nbsp;</p>



<figure class="wp-block-image size-large"><img alt="Screenshot of the Autodesk ObjectARX for AutoCAD 2027 .NET Migration Guide, displaying a table with descriptions on updating .NET applications, along with code snippets and changed enums." class="wp-image-50842" height="480" src="https://i0.wp.com/blog.autodesk.io/wp-content/uploads/2026/04/net_migration_guide.png?resize=1024%2C480&#038;ssl=1" width="1024" /></figure>



<p class="wp-block-paragraph">なお、.NET API の開発者用ガイドは、AutoCAD 2027 のオンライン ヘルプ内で <strong><a href="http://help.autodesk.com/view/OARX/2027/JPN/?guid=GUID-C3F3C736-40CF-44A0-9210-55F6A939B6F2" rel="noreferrer noopener" target="_blank">Managed .NET 開発者用ガイド(.NET)</a></strong>&nbsp;として日本語化されたドキュメントを参照することが出来ます。</p>



<p class="wp-block-paragraph">以前の AutoCAD からの互換情報については、同じく、<strong><a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-A6C680F2-DE2E-418A-A182-E4884073338A" rel="noreferrer noopener" target="_blank">Managed .NET の互換性</a></strong>&nbsp;もご確認ください。</p>



<p class="wp-block-paragraph">AutoCAD 2027 の .NET Wizard は、<strong><a href="https://www.autodesk.com/developer-network/platform-technologies/autocad" rel="noopener noreferrer" target="_blank">https://www.autodesk.com/developer-network/platform-technologies/autocad</a></strong> で Visual Studio 2026 用に今後公開する予定です。</p>



<p class="wp-block-paragraph">ご参考：2バージョン前の<strong><a href="https://forums.autodesk.com/t5/autodesk-community-tips-adnopun/autocad-net-api-net-8-dui-ying-autocad-2025-yong-net-api-wizard/ta-p/12738877" rel="noopener" target="_blank"> AutoCAD .NET API：.NET 8 対応 AutoCAD 2025 用 .NET API Wizard</a></strong>&nbsp;</p>

<p class="wp-block-paragraph"><strong>ActiveX オートメーション（COM）</strong></p>



<p class="wp-block-paragraph">前バージョン用に作成されたアドイン アプリケーションは、そのままロードして実行できるはずです。こちらも、可能であれば、新しいバージョンのタイプライブラリを参照しなおしてテストすることをお勧めします。以前の AutoCAD からの互換情報を含め、タイプライブラリの詳細は、AutoCAD 2027 のオンライン ヘルプ、<strong><a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-927E71C2-E515-438E-9D7A-246D97BEF93F" rel="noreferrer noopener" target="_blank">VBA と ActiveX の互換性</a></strong>&nbsp;をご確認ください。</p>



<p class="wp-block-paragraph">VBA をお使いの場合、VBA コンポーネントは<strong>&nbsp;<a href="http://www.autodesk.com/vba-download-jpn" rel="noopener noreferrer" target="_blank">http://www.autodesk.com/vba-download-jpn</a></strong>&nbsp;から参照可能な Autodesk &nbsp;Knowledge Network 記事からダウンロードすることが出来ます。</p>



<p class="wp-block-paragraph"><strong>AutoLISP</strong></p>



<p class="wp-block-paragraph"><a href="https://blog.autodesk.io/autolisp-development-using-vs-code/" rel="noreferrer noopener" target="_blank"><strong>Visual Studio Code での AutoLISP 開発</strong>&nbsp;</a>でご案内のとおり、AutoCAD 2020 以前からの移行の場合、従来の Visual LISP エディタが Visual Studio Code に置き換えられていますのでご注意ください。AutoCAD 2027 でも <a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-1A8B50AA-1DEA-4853-AAA8-09AF0827A0ED" rel="noreferrer noopener" target="_blank">MAKELISPAPP[LISP アプリを作成]</a>&nbsp;コマンドを使って、配布に適したアプリケーション ファイル（.vlx ファイル）にコンパイルすることが出来ます。コンパイル時には、複数の AutoLISP ファイル（.lsp ファイル）を 1 つの .vlx ファイルにすることが出来るだけでなく、同時にバイナリ ファイル化されるので、ソース コードを保護することも出来ます。なお、コンパイル時には、従来通り、ウィザードが用意されています。</p>



<p class="wp-block-paragraph">以前の AuoCAD バージョンからの互換情報については、AutoCAD 2027 のオンライン ヘルプ、<strong><a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-31FD1A96-C002-434E-8684-63D50BE0CF94" rel="noreferrer noopener" target="_blank">AutoLISP の互換性</a></strong>&nbsp;もご確認ください。</p>



<p class="wp-block-paragraph"><strong>JavaScript</strong></p>



<p class="wp-block-paragraph"><strong><a href="https://help.autodesk.com/view/OARX/2027/JPN/?guid=adsk_jsdev_autocad_javascript_api_about" rel="noreferrer noopener" target="_blank">JavaScript ライブラリ</a></strong>には変更はありませんので移植作業は不要です。</p>



<p class="wp-block-paragraph">その他、アドイン アプリケーションの互換性に関する情報は、AutoCAD 2027 の<strong><a href="https://help.autodesk.com/view/ACD/2027/JPN/?guid=GUID-D54B0935-1638-4F97-8B37-1EC3635A1E71" rel="noreferrer noopener" target="_blank">オンライン ヘルプ</a></strong>をご参照ください。&nbsp;&nbsp;</p>
