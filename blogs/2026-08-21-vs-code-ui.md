オートデスクのデスクトップ製品用アドイン/プラグイン アプリの開発と異なり、APS 開発や MCP サーバー開発では VS Code を用いてご案内するケースが多くあります。 https://code.visualstudio.com/Download からインストーラーを入手して、初めて VS Code をインストールすると、ユーザー インターフェースが英語表示になっています。 ユーザー インターフェースの言語は、既定の英語から日本語に切り替えることが出来ます。言語表示を切り替えるには、まず、[View] メニューから [Command Palette …] を選択します。 Command Palette （コマンド パレット）が表示されたら、プロンプト下に表示される候補から configure display language を見つけてクリックするか、直接 configure display language と入力してリターンキーを押下してください。 設定可能な言語パックが一覧表示されたら、日本語 (ja) をクリックすると、日本語言語パック（Japanese Language Pack for Visual Studio Code のダウンロードとインストールが始まります。 日本語言語パックがインストールされると、VS Code の再起動を促すダイアログが表示されます。[
